# 性能测试说明

不同阶段的样本与测试流程不同，请勿跨表比较。MiB = 1024² 字节，后台 RSS 不等于完整应用所有进程之和。

## 4.1.3 → 4.1.4：内存优先优化

2026-09-09，Windows x64 / Python 3.13 Conda。隔离 SQLite 副本包含 **533,293 条用量事件**。每个版本在独立进程中连续构建三轮汇总，构建下一轮时保留上一轮结果。RSS 每约 50 ms 采样，完成后显式 GC，再读取保留内存。基线为公开 4.1.3 源码包。

| 指标 | 4.1.3 | 4.1.4 优化测量 |
| --- | ---: | ---: |
| 首轮峰值 RSS | 376.9 MiB | 137.4 MiB |
| 三轮最高峰值 RSS | 439.0 MiB | 188.1 MiB |
| 三轮 GC 后 RSS | 152.5 / 157.6 / 162.2 MiB | 76.4 / 80.0 / 78.3 MiB |
| 历史列数组及价格数值存储 | 61,861,988 字节 | 49,064,900 字节 |
| 三轮完整重算 | 16.985 / 17.628 / 17.110 秒 | 22.359 / 26.490 / 26.902 秒 |

首轮峰值降低约 64%，连续刷新峰值降低约 57%，GC 后保留内存约减半。**完整重算变慢，是内存优先的取舍，并非所有性能指标都提升。** 数值存储不包含全部 Python 对象开销，不等于 RSS。

测量发生在最终等价微调之前：最终版本将排序预检查的数组切片改为 `pairwise`，避免临时切片。这里保留原始测量，不将其冒充最终版本重新测量结果。

同规模隔离历史副本，仅清除测试副本汇总缓存、保留全部事实。按 API 自报后台 PID 每约 0.3 秒采样，**未强制 GC**；不包含 Qt 界面和单文件启动器。

| 指标 | 4.1.4 EXE | 4.1.5 EXE |
| --- | ---: | ---: |
| 首次观察到完整用量 | 20.27 秒 | 21.07 秒 |
| 全部就绪 | 24.97 秒 | 25.40 秒 |

两次均验证 533,293 条历史总数、分页查询及原生截图成功。4.1.5 是额度与提示修正，两次轻微差异不能解读成新的性能提升。采样可能漏掉短暂峰值。

## 早期紧凑历史改造：610,931 条样本

以下是早期改造记录，不是 4.1.3 → 4.1.4 对比，也不是当前 EXE 实测。旧记录未标注精确提交，仅作历史参考，不用于当前版本占用承诺。

2026-09-09，Windows x64、现有 Python 3.13 Conda 环境；两份代码使用同一份隔离 SQLite 备份。生产数据库未被测试修改。

- 历史 610,931 条，统计时刻固定 2026-09-08 22:00。
- 测试前仅清空测试副本汇总缓存，原始事实不变。
- 独立进程 RSS 每 100 ms 采样；完成后垃圾回收，仍保留可查询历史。
- 相同页面条件：模型 gpt-6-astra，第一页 7 条。
- 旧：峰值 2,112.3 MiB，保留 1,546.6 MiB，冷汇总 26.100 s，分页 89.31 ms。
- 新：峰值 471.5 MiB，保留 116.5 MiB，冷汇总 20.032 s，分页 30.61 ms。
- 总调用、Token、输入、缓存、输出、推理、累计估算费用逐项一致。

优化包括紧凑数组 / 共享维度、按页展开、移除巨大历史 JSON 缓存、按文件复用会话标识与路径排名、轻量临时对象、提前释放中间集合、复用空闲统计、停止隐藏页面重建，以及只缓存材质层而不缓存整个交互界面。

这些数值不是跨机器性能承诺。磁盘缓存、数据规模、进程分配器影响 RSS，Qt 与 EXE 启动器有额外开销。密集产生新记录时仍需处理真实数据量，不截断历史或改变统计口径来换取指标。

## 早期原生界面单独测试

以下保留早期记录，非 4.1.5 重新测量。

匿名演示数据，完整看板 70% 与小窗口同时显示：初始 RSS 98.8 MiB，循环切换页面 100 次后 118.3 MiB。两窗动态绘制占约单个逻辑核心的 38%，隐藏后约 1%；这不是整机 CPU 百分比，也不含后台索引。缓慢材质按 160 ms 更新，保持原来的实际运动速度；图表动画独立运行。关闭动态效果可进一步减少绘制。

另用 100 次筛选弹窗开启 / 替换测试检查对象生命周期，保留弹窗数量为 1，替换后的旧原生控件已销毁，避免随使用次数线性增长。

## 测量边界与使用建议

- 不是专用静默基准机；系统负载、磁盘缓存和分配器影响结果。
- 更大历史、更多导入来源会增加占用，没有固定内存上限承诺。
- 完整应用占用需合计后台、Qt 界面和启动器，而不是只看一个 PID。
- 升级前先退出旧版；核对实际程序路径及后台版本，避免多个版本并行。不要按旧 PID 盲目结束进程。
- 不截断历史，也不通过系统工作集压缩制造低占用。关闭动态效果可减少绘制，但不减少需要处理的历史事实。
- 私人样本和私人截图不公开上传；公开测量口径与摘要不替代你自己数据上的复测。
