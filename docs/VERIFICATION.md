## 手工验收顺序

1. 运行 EXE，小窗口可拖动、置顶、收进托盘并恢复。
2. 收成迷你模式，用上箭头展开；靠近屏幕底部展开时主体仍在屏幕内。
3. 拖动窗口四边 / 四角缩放；完整看板从原生菜单打开，关闭后小窗口仍保留。
4. 切换五页与三个范围，查看模型搜索、多选、历史分页及排序。
5. 在主图滚轮缩放、悬停、双击复位；在模型行打开详情。
6. 调整透明度 / 预设，切换流彩和图表动画，检查圆角外没有彩色矩形。
7. 如需导入，使用另一台电脑的一致性 SQLite 备份；重复导入不重复计数，保留自动备份。
